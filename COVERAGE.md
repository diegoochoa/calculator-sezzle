# Coverage

Both suites are gated at **85%**. The gates fail the build rather than warn, and
both are enforced by `make coverage` from the repository root.

The browsable HTML reports are committed so they can be read without cloning and
running anything:

| | Report | Regenerate |
|---|---|---|
| Frontend | [`frontend/coverage/index.html`](frontend/coverage/index.html) | `npm run test:coverage` |
| Backend | [`backend/coverage.html`](backend/coverage.html) | `make cover-html` |

> **Viewing them on GitHub.** GitHub serves committed `.html` as source rather
> than rendering it. To read a report in a browser without cloning, prefix the
> file's URL with `https://htmlpreview.github.io/?` — or clone and open the paths
> above directly. The numbers below render natively either way.

Regenerate both at once, with paths printed:

```bash
make coverage-html
```

## Beyond line coverage

Two things the percentages do not capture:

- **`FuzzParse`** runs the lexer and parser against generated input, asserting
  they never panic and never return a success the transport layer cannot encode.
  It has survived 3.5M executions. `cd backend && make fuzz`.
- **The OpenAPI drift tests** fail the build if a route is documented but not
  served, or served but not documented, if any `$ref` fails to resolve, or if
  the catalog schema stops matching what the handler emits.
